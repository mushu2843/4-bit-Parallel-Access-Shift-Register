# 4-Bit Parallel Access Shift Register

## Overview
This project implements a 4-bit Parallel Access Shift Register using Verilog HDL.

## Features
- Parallel Load
- Shift Left
- Shift Right
- Hold Operation
- Reset Function

## Tools Used
- Quartus Prime Lite
- ModelSim Intel FPGA Edition
- Verilog HDL

## Files
- shift_register.v
- shift_register_tb.v
- waveform.png

## Simulation Result
The design was verified successfully using ModelSim waveform simulation.
